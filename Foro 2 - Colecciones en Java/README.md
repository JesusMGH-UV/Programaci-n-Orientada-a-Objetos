# Foro 2 - Colecciones en Java (ArrayList)

## Objetivos de la Presentación

Este repositorio contiene el material y la presentación sobre el funcionamiento interno, características clave y escenarios de aplicación de `ArrayList` en Java.

* Comprender la estructura interna, el redimensionamiento dinámico y la gestión de capacidad en `ArrayList`.
* Analizar la complejidad algorítmica y contrastar su rendimiento frente a arreglos nativos y `java.util.LinkedList`.
* Identificar los escenarios de uso óptimos en desarrollo real (mapeo de consultas, procesamiento por lotes) y sus limitaciones en concurrencia.
